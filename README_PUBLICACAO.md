# Site completo — Paula do Nascimento

## Publicação no GitHub Pages

Este pacote substitui os arquivos atuais do repositório do site.

### Antes de começar
Baixe uma cópia do repositório atual ou mantenha o ZIP anterior como backup.

### Passo a passo
1. Extraia o arquivo ZIP no computador.
2. Abra o repositório `pauladonascimento` no GitHub.
3. Na aba **Code**, clique em **Add file > Upload files**.
4. Arraste todos os arquivos e a pasta `assets` extraídos deste pacote.
5. O GitHub solicitará confirmação para substituir arquivos com o mesmo nome.
6. No campo de mensagem, escreva: `Publicação do site completo`.
7. Clique em **Commit changes**.
8. Aguarde de 2 a 5 minutos.
9. Abra `https://pauladonascimento.com.br`.
10. Pressione `Ctrl + F5` no Windows para carregar a versão atualizada.
