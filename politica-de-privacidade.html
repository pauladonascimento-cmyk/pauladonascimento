Política de Privacidade

Como os dados enviados pelo site são utilizados.

Esta página explica, de forma simples, o tratamento das informações fornecidas nos formulários de contato.

Voltar ao contato
Coleta de dados

Dados enviados voluntariamente.

Os formulários solicitam nome, telefone, e-mail e mensagem. Essas informações são utilizadas exclusivamente para responder ao contato e compreender a solicitação apresentada.

Ao enviar o formulário, o WhatsApp é aberto no dispositivo do visitante. O site não mantém banco de dados próprio com essas informações.

Links e atualizações

Serviços externos.

O site pode conter links para WhatsApp, Instagram, YouTube, Hotmart, páginas de vendas e Google Maps. Ao acessar esses serviços, aplicam-se as políticas de privacidade de cada plataforma.

Esta política poderá ser atualizada sempre que novas funcionalidades forem adicionadas ao site.
